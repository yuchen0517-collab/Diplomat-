# Diplomat 外交谈判模拟器

基于大语言模型与谈判规则引擎的交互式外交谈判教学作品。玩家可以参与双边或多边谈判，也可以观察九方代表围绕历史议题展开推演；系统会同步呈现主体利益、国际形象、盟友信任、隐藏任务、突发事件、事实核查与复盘报告。

本目录为**完整源代码提交包**，对应 `webdemo1.9` 版本。网页、后端、Agent 引擎、知识库、本地字体、测试和说明文档均已包含，不依赖原项目中的其他目录。

> **评委快速入口**：请优先阅读 [`评委使用说明.md`](评委使用说明.md)，其中包含一键启动、10–15 分钟推荐评审路线、界面注释、评分说明与常见问题。
>
> **技术设计文档**：[`智能体设计说明书.md`](智能体设计说明书.md) 详细说明智能体架构、角色建模、知识增强、输出校验、博弈与事件算法、评分机制和扩展方式。

## 一、运行环境

* 操作系统：Windows 10 / 11（推荐）；其他可运行 Python 的桌面系统也可使用命令行启动。
* Python：**3.10 或更高版本**。
* 浏览器：最新版 Microsoft Edge 或 Google Chrome。
* 运行依赖：网页版与命令行 Agent 仅使用 Python 标准库，**无需安装第三方 Python 包**。
* 网络：离线演示不需要网络；调用真实模型时才需要网络和有效 API Key。

Python 源代码无需单独编译，可直接运行。安装 Python 时请勾选“Add python.exe to PATH”。

## 二、最快启动方式

1. 保持本目录内部结构不变，双击 **`start.bat`**。
2. 启动器会查找 Python、启动本地服务，并自动打开首页。
3. 若浏览器未自动打开，请访问 **http://127.0.0.1:8001**。
4. 使用结束后，关闭启动时出现的命令行窗口即可停止服务。

提交包中的 `key.txt` 是**空文件**，因此默认进入离线演示模式，无需申请或填写密钥即可评审主要流程。

也可以在当前目录打开终端执行：

```powershell
py -3 server.py
```

不自动打开浏览器：

```powershell
py -3 server.py --no-browser
```

## 三、建议评审路线

1. 在首页进入“学习模式”，查看三关外交谈判教学内容。
2. 返回首页，进入“双边对谈”，选择议题与代表团。（算力与芯片出口管制议题已内置知识库，建议优先选择，并选择中美两国）
3. 在谈判页使用每轮三张策略卡，观察行动点、三项指数、顾问建议、事件卡和事实核查。
4. 点击“结束谈判”，查看谈判结果、评分、时间线和隐藏任务复盘。
5. 返回首页体验“多边磋商”或“观战模式”；观战页可查看九方席位、内心 OS、谈判树和立场演变。（联合国海洋法已内置知识库，建议优先选择）

> 离线模式使用内置发言与本地规则，主要用于完整展示产品流程；配置真实模型后，Agent 会根据议题、人设和知识库动态生成回应。

## 四、主要功能

* **双边谈判**：每轮 2 行动点，支持 1 点战术卡、2 点战略卡及组合出牌；后端校验手牌、重复用卡和行动点。
* **多边谈判**：多个代表团按轮次参与，围绕不同立场与红线展开博弈。
* **九方观战**：半弧谈判桌、自动/手动播放、三种解说口吻、发言高亮和阶段章节。
* **谈判分析**：实时谈判树、立场演变、内心 OS、战情解说和事件历史。
* **规则结算**：主体利益、国际形象、盟友信任三指数，以及红线、合作窗口、隐藏任务和博弈规则。
* **知识增强**：按议题注入事实卡，避免不同议题知识混用；对发言中的数字和年份进行核查。
* **突发事件**：算力、海洋法和通用花絮事件卡，按议题与受影响方结算。
* **学习模式**：三关课程、笔记和进度解锁。
* **复盘报告**：总分与等级、发言时间线、关键事件、隐藏任务、改进建议和战报复制。
* **离线降级**：未配置密钥或现场无网络时，仍可使用内置内容演示。
* **本地资源**：界面字体随包附带，页面运行不依赖外部字体或前端 CDN。

## 五、在线模型配置（可选）

作品支持 DeepSeek API。推荐使用环境变量，避免把密钥写入提交文件：

```powershell
$env:DEEPSEEK\\\_API\\\_KEY = "你的 API Key"
py -3 server.py
```

也可以在本机把密钥写入根目录的 `key.txt`，保存后重新启动。**不要把真实密钥随作品公开提交。**

可选环境变量：

|变量|默认值|用途|
|-|-:|-|
|`DEEPSEEK\\\_BASE\\\_URL`|DeepSeek 官方接口|自定义兼容接口地址|
|`DEEPSEEK\\\_MODEL`|`deepseek-chat`|模型名称|
|`DEMO\\\_PORT`|`8001`|本地服务端口|
|`DEMO\\\_HOST`|`0.0.0.0`|监听地址；仅本机使用可设为 `127.0.0.1`|
|`DEMO\\\_MAX\\\_ROUNDS`|`30`|双边/多边回合上限|
|`DEMO\\\_OBSERVE\\\_ROUNDS`|`0`|观战回合上限；0 表示不限|
|`DEMO\\\_SPEECH\\\_LIMIT`|`350`|单条发言最大字符数|
|`DEMO\\\_EVENT\\\_PROB`|`0.2`|每轮突发事件概率|
|`DEMO\\\_TASK\\\_JUDGE`|`1`|是否使用模型判定隐藏任务；离线演示可设为 `0`|

双击 `检查Key.bat` 可检查当前是在线模式还是离线模式，不会显示密钥内容。

## 八、知识库维护（可选）

直接运行作品不需要安装依赖。只有修改 Excel 事实卡并重新导入时，才需要：

```powershell
py -3 -m pip install "openpyxl>=3.1,<4"
py -3 knowledge/导入事实卡.py knowledge/算力与芯片出口管制\\\_事实卡\\\_v3.xlsx
```

日常运行使用 `knowledge/topics/\\\*.json` 和 `knowledge/event\\\_cards.json`。知识卡采集规范、模板及海洋法来源说明均保留在 `knowledge/` 中。

## 九、注意事项与已知限制

* 谈判会话保存在后端内存中，重启服务后当前对局会清空；场景与复盘数据保存在浏览器 `localStorage`。
* 离线回放中的发言与部分结算数字是演示样例，不代表真实模型输出。
* 内心 OS 与复盘建议主要由规则生成，不额外调用模型。
* 多边模式每轮由一位对手发言，并非多个模型同时生成。
* 只有配置了对应知识库的议题才显示事实“册载”与历史阶段。
* 真实模型输出受网络、API 服务与模型状态影响；评审离线流程无需这些外部条件。
